Como habilitar o Monitoramento em Tempo Real com o Google Analytics (GA4)

Este dashboard vem configurado com um motor simulador avançado para validação imediata. Para conectá-lo a um fluxo real de produção do evento da HDI Seguros, siga o passo a passo de integração nativa com o **Google Analytics 4 (GA4)** e **Google Cloud API Console**:

1

Obtenha o ID de Medição do GA4

Acesse o Google Analytics. Crie ou use uma propriedade existente. Acesse Administrador > Fluxos de dados > Escolha seu Fluxo Web e copie o ID de Medição (no formato G-XXXXXXXXXX). Coloque no campo GA4_MEASUREMENT_ID no arquivo analytics-config.js.

2

Obtenha o ID da Propriedade no GA4

No painel do Google Analytics, acesse Administrador > Configurações da Propriedade e copie o ID da Propriedade (uma sequência de apenas números inteiros, ex: 123456789). Cole no campo GA4_PROPERTY_ID no arquivo analytics-config.js.

3

Crie as Credenciais de APIs do Google Cloud

Acesse o Google Cloud Console. Crie um projeto e acesse APIs e Serviços > Biblioteca. Ative a Google Analytics Data API. Depois, vá em Credenciais, crie uma credencial do tipo ID do Cliente OAuth 2.0 (Tipo de aplicativo: Aplicativo da Web). Insira as URLs autorizadas do seu site: https://hdi-mapa-junino.github.io e origens locais como http://localhost. Copie o ID do Cliente OAuth obtido e insira no campo GOOGLE_CLIENT_ID no arquivo analytics-config.js.

4

Suba as configurações ao GitHub

Após salvar o arquivo analytics-config.js no seu editor de código local com os dados corretos, execute um commit e faça o push. Seus scripts começarão a computar os acessos instantaneamente e, ao clicar na aba Google GA4 no topo do Dashboard, você poderá logar com sua conta Google com acesso ao Analytics e visualizar os dados reais integrados diretamente da API!
